# Code of conduct

## The standard

Be decent. Assume the other person is trying to help. Criticise the work, not
the person making it, and take criticism of your own work the same way.

Unacceptable: harassment, personal attacks, sustained disruption, publishing
someone's private information, and sexual attention or advances of any kind.

## Scope

This applies in the issue tracker, in pull requests, in commit messages and in
any other space where someone is representing this project.

## Reporting

Report through GitHub's **private vulnerability reporting** on this repository
(Security → Report a vulnerability). It is a private channel to the maintainers
and is used here for conduct reports as well, because it is the only private
channel this project has.

Reports are read by the maintainers, who may warn, block, or remove
contributions. There is no committee and no appeals process: this is a small
project maintained by one person, and pretending otherwise would be worse than
saying so.

## Attribution

The substance follows the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, shortened to what this project can actually promise to enforce.
